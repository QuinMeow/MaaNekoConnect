## 范围与判据

用户授权逐项实机测试，并允许默认电池、金币和礼物次数消耗；禁止钻石消费、广告和家具强化券。本轮固定使用 `127.0.0.1:5557`，实机标题页显示游戏 `2.2.0`，识别尺寸为 `720x1280`。执行仓库真实资源和项目私有 Python 的 `agent/main.py`，没有新增产品业务 CLI、切分支、提交或推送，也没有同步已安装 MFAAvalonia 的资源副本。
